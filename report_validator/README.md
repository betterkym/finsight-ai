# FinSight 리포트 신뢰도 검증

증권사 리포트의 목표가, 투자의견, 본문 의견을 DART 재무·공시, KRX 주가·수급, 증권사 목표가 평균, 발행 이후 이슈와 대조해 신뢰도 점수와 종합 해석 보고서를 만드는 Streamlit 앱입니다.

## 빠른 시작

```bash
streamlit run report_validator/app_finsight.py
```

루트 앱에서 비교용 `Analyst Mode`까지 함께 보려면:

```bash
streamlit run app.py
```

## 제품 흐름

### 1. 리포트 입력

- 종목명 또는 종목코드로 회사와 목표가 평균을 찾습니다.
- PDF를 여러 개 업로드할 수 있습니다.
- PDF에서 증권사, 발행일, 투자의견, 목표가, 본문 일부를 읽습니다.
- 목표가·투자의견을 읽지 못한 리포트는 비교표와 중앙값 계산에서 제외하고, 사이드바에서 직접 입력하면 다시 반영합니다.

### 2. 목표가 편차

업로드 리포트들의 목표가를 표로 정리하고, 증권사 목표가 평균과 비교합니다.

- 평균권: 시장 기대와 크게 다르지 않은 구간
- 평균보다 공격적: 높은 목표가를 정당화할 추가 근거가 필요한 구간
- 평균보다 보수적: 다른 리포트 대비 낮은 기대를 반영한 구간

### 3. 발행 이후 괴리

각 리포트의 발행일 이후 실제 주가, 남은 상승여력, 수급, 공시 변화를 확인합니다. 리포트가 일찍 발행되어 이후 이슈를 반영하지 못했거나, 매수 의견과 반대로 수급이 움직인 경우 신뢰도를 보수적으로 봅니다.

### 4. 필요 실적

목표가가 성립하려면 EPS가 얼마나 좋아져야 하는지 역산합니다. 평균 성장률만 쓰면 기저효과에 흔들릴 수 있어 과거 중앙값 성장률과 함께 봅니다.

### 5. 본문 의견 검증

PDF 본문에서 반복되는 논점을 추출합니다.

- 실적 성장
- 수익성·마진
- 해외·수출
- 원가·비용
- 주가·수급
- 현금흐름·투자

리포트끼리 같은 방향으로 말하는 부분과 해석이 갈리는 부분을 나누고, DART 재무·주가·수급과 대조합니다. 본문에서 좋게 본 부분이 실제 데이터로 덜 확인되면 최종 신뢰도에서 추가 차감됩니다.

### 6. 종합평가

기본 점수는 다음 세 항목으로 계산합니다.

| 항목 | 배점 | 산정 방식 |
|------|------|-----------|
| 목표가 편차 | 30점 | 증권사 목표가 평균 대비 z-score 구간 |
| 발행 이후 괴리 | 30점 | 발행 후 경과일, 수급 반대, 상승여력 소진 |
| 필요 실적 | 40점 | 목표가에 필요한 EPS 성장률과 과거 성장률 비교 |

이후 기존 애널리스트 워크벤치의 재무 이상징후, 현금흐름, 가격·수급 괴리, PDF 본문 의견 검증을 객관분석 차감으로 더합니다. 최종 결과는 리포트 신뢰도 점수와 HTML/PDF 보고서로 출력됩니다.

## 연결 데이터와 반영 위치

| 데이터 | 반영 위치 |
|--------|-----------|
| 업로드 PDF | 리포트 기준값, 목표가 비교, 본문 의견 검증 |
| 네이버 금융 목표가 평균 | 목표가 편차 |
| OpenDART 분기 재무 | 필요 실적, 재무 이상징후, 현금흐름 검증 |
| OpenDART 공시·지분공시 | 발행 이후 괴리, 업데이트 이슈 |
| KRX/pykrx 가격·수급 | 발행일 주가, 현재 주가, 외국인·기관 수급 |
| Naver Search | 발행 이후 뉴스·시장 이슈 보조 |
| FRED/ECOS/World Bank | 환율·원가·거시 변수 보조 |

연결되지 않은 데이터는 해당 항목만 비워두고, 계산 가능한 항목은 그대로 진행합니다.

## 주요 파일

```text
report_validator/
├── app_finsight.py          # Streamlit UI와 입력 흐름
├── finsight_modules.py      # 목표가 평균 대비 위치, EPS 역산
├── timeline_module.py       # 발행 이후 주가·수급·공시 타임라인
├── scoring_module.py        # 기본 신뢰도 점수와 등급
├── report_assessor.py       # 재무 이상징후·현금흐름·수급 괴리 차감
├── evidence_audit.py        # 점수 근거, 원자료 연결, 자료 흐름
├── retail_report.py         # HTML/PDF 다운로드 보고서
├── consensus_crawler.py     # 네이버 금융 리서치 목록·목표가 평균
└── demo_data.py             # DART 미연결 시 폴백 데이터
```

## 점수 기준

| 등급 | 점수 | 해석 |
|------|------|------|
| A | 75+ | 신뢰할 만함 |
| B | 60+ | 대체로 무난 |
| C | 45+ | 주의 필요 |
| D | 30+ | 신뢰도 낮음 |
| E | 30 미만 | 낙관 편향 강함 |

점수는 종목 추천이 아니라 리포트 신뢰도 평가입니다. 같은 종목이라도 업로드한 리포트의 발행일, 목표가, 본문 의견에 따라 결과가 달라집니다.

## 데모 데이터

`demo_data.py`는 DART 재무 수집이 실패했을 때 화면이 끊기지 않도록 사용하는 폴백 데이터입니다. 실제 평가에서는 DART 연결 결과가 우선됩니다.

## 개발 메모

- PDF 텍스트 추출은 `pypdf`와 `pdfplumber`를 함께 사용합니다. 표·2단 편집·글자 간격이 깨진 증권사 PDF는 두 방식의 결과를 합쳐 읽습니다.
- 여러 PDF 업로드 시 목표가·투자의견이 모두 확인된 리포트만 비교표와 중앙 목표가 계산에 포함합니다.
- 본문 의견 검증은 PDF에서 읽은 문장을 기반으로 하며, 원문 추출 품질이 낮으면 사이드바 직접 입력과 원문 확인이 필요합니다.
