# FinSight 리포트 신뢰도 검증

증권사 리포트의 목표가와 투자의견을 DART 재무·공시, KRX 주가·수급, 증권사 목표가 평균, 발행 이후 공시·뉴스·지분 변동으로 다시 대조해 신뢰도 점수와 종합 해석 보고서를 제공하는 도구입니다.

---

## 빠른 시작

```bash
streamlit run report_validator/app_finsight.py
```

API 키 없이 **농심 데모 데이터**로 즉시 실행됩니다.
(DART_API_KEY가 있으면 실데이터 자동 연결)

---

## 설계 원칙

### 검증 구조

리포트의 결론을 그대로 받아들이지 않고, 목표가의 위치, 발행 후 변화, 목표가 가정을 분리해 점수화합니다.

#### 페인포인트 → 검증축 1:1 대응

| 투자자의 문제 | 검증 방법 | 질문 |
|---|---|---|
| 검증 대상 | 검증 방법 | 해석 |
|---|---|---|
| 목표가 수준 | **분포 위치** | 시장 평균 대비 공격적인지 확인 |
| 발행 이후 변화 | **시점 유효성** | 주가·수급·공시·뉴스 변화가 리포트 전제를 바꿨는지 확인 |
| 목표가 가정 | **가정 현실성** ★ | 필요한 EPS 성장률이 과거 실적 범위에서 가능한지 확인 |

#### 각 축의 역할

**① 공간축 (30점) — 분포 정합성**
```
"이 목표가는 8개 중 상위 12%"
→ 혼자 튀는지 알 수 있다
```

**② 시간축 (30점) — 시점 유효성**
```
"발행 36일 경과, 외국인 -180억 순매도"
→ 선반영·수급 괴리를 본다
```

**③ 논리축 (40점) — 가정 현실성 ★ 핵심**
```
"필요 성장 +32% vs 보통 해 +5%"
→ 목표가가 현실적인지 판단한다
```

#### 변동성 보정 (핵심 차별점)

단순 평균은 기저효과로 정확도가 낮습니다.
```
농심 사례:
- 평균 성장률: +36% (2023년 +119% 한 방에 왜곡)
- 중앙값: +5% (실제 전형적인 성장)
→ 필요 성장이 보통 해의 6배 = "낙관"
```

## 사용 가이드

### 입력

**사이드바에서 입력:**
- 종목명 또는 종목코드 (필수)
- 검증할 리포트:
  - 증권사명
  - 발행일 (date picker)
  - 목표가 (숫자)
  - 투자의견 (매수/중립/매도)

**자동 수집됨:**
- DART 과거 분기 재무
- 현재가
- 발행 후 외국인 수급
- 동종기업 데이터

### 출력

**통합 검증 카드 (상단)**
```
신뢰도: 37/100
등급: D (신뢰도 낮음)
★★☆☆☆
```

**3개 탭**
- ① 혼자 튀나? — 분포 위치, 의견 집계, 적정가 범위
- ② 지금도 유효? — 타임라인, 선반영 소진율, 수급 괴리
- ③ 숫자가 성립? — 역산 계산, 성장률 비교, 시나리오 분석
- 근거·출처 — 계산식 상세

### 평가 기준

| 등급 | 점수 | 평가 |
|------|------|------|
| A | 75+ | 신뢰할 만함 |
| B | 60+ | 대체로 무난 |
| C | 45+ | 주의 필요 |
| D | 30+ | 신뢰도 낮음 |
| E | 미만 | 낙관 편향 강함 |

## 파일 구조

```
report_validator/
├── app_finsight.py              # 메인 UI
├── finsight_modules.py          # 분포·역산
├── timeline_module.py           # 발행 후 변화
├── scoring_module.py            # 3축 점수 통합
├── demo_data.py                 # 농심 데모
└── README.md                    # 이 파일
```

### 핵심 함수

**모듈1 — 분포 위치**
- `locate_in_distribution()` — 목표가가 분포에서 어디인지
- `aggregate_opinions()` — 의견 집계 (매수/중립/매도)

**모듈2 — 시점 정합성**
- `build_post_publish_timeline()` — 발행 후 타임라인
- `fetch_foreign_net()` — 외국인 수급 (pykrx)

**모듈3 — 가정 역산**
- `reverse_engineer_target()` — 목표가 역산 + 변동성 보정

**모듈4 — 신뢰도 점수**
- `build_report_verdict()` — 3축 종합 + 평가 의견
- `score_space()`, `score_time()`, `score_logic()` — 각 축 점수

## 검증 기준 (농심)

```
① 공간축: 14/30
   8개 증권사 중 상위 12%, 평균 대비 +8.9%

② 시간축: 17/30
   발행 36일 경과, 외국인 -180억 순매도 괴리

③ 논리축: 6/40
   필요 +32% vs 보통 해 +5% (CV 1.6 매우높음)

─────────────────
종합: 37/100 (D등급)

평가: "한화투자증권 목표가 550,000원은 
       그대로 믿기 어렵습니다"
```

**이 결과가 재현되면 정상 작동입니다.**
