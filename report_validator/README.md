# FinSight 3축 리포트 검증 도구

개인투자자가 증권사 리포트를 검증하는 도구입니다.
"이 리포트, 믿어도 되나?"를 한 화면에서 100점으로 평가합니다.

---

## 빠른 시작

```bash
streamlit run app_finsight.py
```

API 키 없이 **농심 데모 데이터**로 즉시 실행됩니다.
(DART_API_KEY가 있으면 실데이터 자동 연결)

---

## 설계 원칙

### 왜 정확히 3축인가?

개인투자자가 리포트를 받고 던지는 질문은 정확히 3가지입니다.

#### 페인포인트 → 검증축 1:1 대응

| 투자자의 문제 | 검증 방법 | 질문 |
|---|---|---|
| 한 리포트만 봐서 높낮이를 모름 | **공간축** | 다른 증권사보다 튀나? |
| 발행 시점에 이미 주가 반영됨 | **시간축** | 발행 후 상황 바뀌었나? |
| 목표가 가정이 뭔지 모름 | **논리축** ★ | 이 목표가 숫자가 성립하나? |

#### 각 축의 역할

**① 공간축 (30점) — 분포 정합성**
```
"이 목표가는 8개 중 상위 12%"
→ 혼자 튀는지 알 수 있다
```

**② 시간축 (30점) — 시점 유효성**
```
"발행 36일 경과, 외국인 -180억 순매도"
→ 선반영·수급 괴리를 본다
```

**③ 논리축 (40점) — 가정 현실성 ★ 핵심**
```
"필요 성장 +32% vs 보통 해 +5%"
→ 목표가가 현실적인지 판단한다
```

#### 변동성 보정 (핵심 차별점)

단순 평균은 기저효과로 정확도가 낮습니다.
```
농심 사례:
- 평균 성장률: +36% (2023년 +119% 한 방에 왜곡)
- 중앙값: +5% (실제 전형적인 성장)
→ 필요 성장이 보통 해의 6배 = "낙관"
```

## 사용 가이드

### 입력

**사이드바에서 입력:**
- 종목명 또는 종목코드 (필수)
- 검증할 리포트:
  - 증권사명
  - 발행일 (date picker)
  - 목표가 (숫자)
  - 투자의견 (매수/중립/매도)

**자동 수집됨:**
- DART 과거 분기 재무
- 현재가
- 발행 후 외국인 수급
- 동종기업 데이터

### 출력

**통합 검증 카드 (상단)**
```
신뢰도: 37/100
등급: D (신뢰도 낮음)
★★☆☆☆
```

**3개 탭**
- ① 혼자 튀나? — 분포 위치, 의견 집계, 적정가 범위
- ② 지금도 유효? — 타임라인, 선반영 소진율, 수급 괴리
- ③ 숫자가 성립? — 역산 계산, 성장률 비교, 시나리오 분석
- 근거·출처 — 계산식 상세

### 평가 기준

| 등급 | 점수 | 평가 |
|------|------|------|
| A | 75+ | 신뢰할 만함 |
| B | 60+ | 대체로 무난 |
| C | 45+ | 주의 필요 |
| D | 30+ | 신뢰도 낮음 |
| E | 미만 | 낙관 편향 강함 |

## 파일 구조

```
report_validator/
├── app_finsight.py              # 메인 UI
├── validator.py                 # 3개 모듈 + 점수 (통합)
├── demo_data.py                 # 농심 데모
└── README.md                    # 이 파일
```

### 핵심 함수 (validator.py)

**모듈1 — 분포 위치**
- `locate_in_distribution()` — 목표가가 분포에서 어디인지
- `aggregate_opinions()` — 의견 집계 (매수/중립/매도)

**모듈2 — 시점 정합성**
- `build_post_publish_timeline()` — 발행 후 타임라인
- `fetch_foreign_net()` — 외국인 수급 (pykrx)

**모듈3 — 가정 역산**
- `reverse_engineer_target()` — 목표가 역산 + 변동성 보정

**모듈4 — 신뢰도 점수**
- `build_report_verdict()` — 3축 종합 + 평가 의견
- `score_space()`, `score_time()`, `score_logic()` — 각 축 점수

## 검증 기준 (농심)

```
① 공간축: 14/30
   8개 증권사 중 상위 12%, 평균 대비 +8.9%

② 시간축: 17/30
   발행 36일 경과, 외국인 -180억 순매도 괴리

③ 논리축: 6/40
   필요 +32% vs 보통 해 +5% (CV 1.6 매우높음)

─────────────────
종합: 37/100 (D등급)

평가: "한화투자증권 목표가 550,000원은 
       그대로 믿기 어렵습니다"
```

**이 결과가 재현되면 정상 작동입니다.**

## 핵심 원칙

✅ **사실만**: 의견을 새로 만들지 않습니다.

✅ **추천금지**: "사세요/파세요"는 절대 말하지 않습니다.

✅ **판단은 투자자**: FinSight는 맥락만 제공합니다.
